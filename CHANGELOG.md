# Changelog

## 0.2.1 — 2026-11-27

- Original framebuffer viewer and interactive touchscreen event injection.
- Inverse touchscreen calibration and expanded raw coordinate bounds.
- Local SSH-only access, origin and per-process token checks.
- Hardware-tested menu navigation, firmware check and systemd startup after power cycle on one printer.
- Community documentation and new, not yet hardware-tested installation helpers.

## Unreleased

- Fullscreen, scaling, screenshots and reconnect improvements.
