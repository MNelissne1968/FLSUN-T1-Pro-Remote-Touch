# Roadmap

- v0.2.1: hardware-tested original touchscreen control (main).
- v0.2.2 development: browser display controls and diagnostics.
- v0.3.0 Builds 01–04: monitoring dashboard, Moonraker integration and display options.
- Build 05: interactive simulation.
- Builds 06A–06D: safety checks, short-lived authorization, simulation API and HTTP hardening. Previous development checkpoint.
- Build 06E1: validated virtual touch bridge and offline protocol tests. Current development checkpoint.
- Build 06E2: planned browser-to-virtual-bridge integration.
- Build 06E3: planned physical integration, only after the printer is idle and cold; address legacy endpoint bypass.
- Build 07: planned release candidate.
- v0.3.0: planned public release after validation.
- Future exploration: camera, mobile usability and native-resolution improvements.

No delivery dates are promised. Contributions and reproducible bug reports are welcome.
